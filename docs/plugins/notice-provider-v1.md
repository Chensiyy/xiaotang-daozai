# 本机通知来源接口 v1

本机接入端可以向岛仔发送任务完成提醒，并在用户点击后打开原会话。接入端负责订阅客户端的事件、定位会话和恢复窗口。岛仔负责通知、未读状态和正文预览。

## 用户授权

1. 在「设置 → 消息提醒 → 本机通知来源」填写接入端提供的来源 ID，以及要显示在岛上的名称。
2. 点「授权来源」，再点「复制凭据路径」，把路径交给接入端。凭据文件内含访问令牌，只交给自己信任的接入端。
3. 开启提醒总开关。要在岛上阅读完成正文，再开启「显示通知正文」。

撤销授权后，该来源无法再发出通知或取走跳转请求，岛上的对应提醒也会清除。

来源 ID 建议使用 `作者.接入端`，例如 `example.agent`，最长 64 个 ASCII 字符。各段允许小写字母、数字和连字符，并以字母或数字开头。每个接入端只读取自己的凭据文件，不把凭据内容写入日志或上报。默认路径是 `%APPDATA%\Daozai\plugin-notices\<来源 ID>.json`。设置中复制的路径也适用于自定义数据目录。

## 连接

凭据文件包含 `version`、`host`、`port`、`source`、`token`。当前版本为 `1`。每次连接岛仔前重新读取此文件，避免使用上次启动的端口和令牌。

通过 TCP 连接凭据中的 `127.0.0.1` 和端口。每个连接发一行 UTF-8 JSON，以换行结束。岛仔回一行 JSON 后关闭连接。每个请求均需带凭据里的 `version`、`source`、`token`，以及一个 `method`。成功响应含 `ok: true`，失败响应含 `ok: false` 和可用于诊断的 `error`。

| method | 附加字段 | 行为 |
| --- | --- | --- |
| `status` | 无 | 返回 `preview`。为 `false` 时接入端可省略正文。 |
| `complete` | `id`，可选 `session` 和 `markdown` | 发送一条完成提醒。将 `id` 设为该来源内本轮唯一的标识。同一轮重试沿用同一个 ID。`session` 是接入端能识别的会话标识，无会话可打开时省略。 |
| `poll_open` | 无 | 取本来源的待办跳转。返回 `open: null` 或 `open: { "request_id": "...", "session": "..." }`。 |
| `ack_open` | `request_id`、`opened` | 完成跳转后返回结果。只有定位到对应会话，才回 `opened: true`。不存在的会话、切换失败或无法确认时回 `false`。 |

将示例中的 `<token>` 换成凭据文件中的令牌。

```json
{"version":1,"source":"example.agent","token":"<token>","method":"complete","id":"turn-42","session":"conversation-42","markdown":"## 任务完成\n- 已整理会议记录"}
```

`id`、`session`、`markdown` 分别最多 128 字节、512 字节、32 KiB。整条 JSON 请求最多 128 KiB。队列忙时可以稍后用原 ID 重试。

接入端可以在运行期间定期取 `poll_open`。收到跳转请求后，用自己的客户端 API 打开会话，5 秒内发送 `ack_open`。跳转请求过期或失败时，岛仔保留角标，用户可以重试。阅读岛上的结果也可以清除对应的未读状态。

正文仅作本机预览，由提醒总开关和正文预览开关控制。完成内容和会话标识不会写入通知历史。正文支持常见的 Markdown 标题、列表和代码块，以文本渲染。

此接口目前用于验收版的手动接入。Codex 和 DeepSeek Harness 的接入端由作者单独提供。
