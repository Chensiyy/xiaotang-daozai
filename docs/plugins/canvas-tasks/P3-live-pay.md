# P3：实时工资

插件仓分支 `feat/official-live-pay`，插件 ID `daozai.live-pay`。依赖 A、B、C，以及 P1 的投稿校验。设计稿：「理想版 · 实时工资」。共同规则见 [README](README.md)。

参考 `spike/examples/live-pay` 的计算部分。

## 设置

| 键 | 类型 | 默认 |
| --- | --- | --- |
| `salary` | number，元/月 | 无，未填时页面提示去设置 |
| `start`、`end` | time | 09:00、18:00 |
| `lunch_start`、`lunch_end` | time | 12:00、13:30 |
| `lunch_paid` | switch | 关：午休不计薪 |
| `days` | weekdays | 一至五 |
| `pinned_show` | choice | 金额（默认）、下班倒计时、两者轮换 |

日薪 = 月薪 ÷ 当月工作日数；每秒 = 日薪 ÷ 当天计薪秒数（不计薪的午休不算在内）。

## 界面

整页画布，高 200。

- **标题下一行**：「今天已赚」加每秒增量。
- **计价器**：
  - 「¥」加每位一格的数字。整数位数按金额变化，小数两位。
  - 用 `counter` 绑定，开 `roll`，最后一位用强调色。
- **游戏经验条**，高 16：
  - 左边是「LV.N」，N 为当前第几个工作小时。
  - 进度用 `progress` 绑定，从上班到下班。
  - 填充带斜条纹，开 `loop: flow`，有外发光。
  - 每小时一条分隔线。
  - 午休段用橙色斜纹标出。
  - 上方 12:00 处放饭碗检查点，末端放终点旗。
  - 金币小人沿进度移动，开 `loop: bob`。
- **底部一行**：
  - 左边「第 N 小时 · 本小时已赚 ¥x」。
  - 右边绿色胶囊「距离通关 HH:mm:ss」，用 `countdown` 绑定。

## 状态切换

- 用 `next_refresh_at` 在上班、午休开始、午休结束、下班这几个时刻刷新。
- 午休时：
  - 经验条换成橙色回血条，小人趴下睡觉并冒「Zz」（`loop: pulse`）。
  - 不计薪时计价器停住；计薪时照常跳动。
- 下班后：
  - 显示「通关！今天到手 ¥x」。
  - 小人举旗，撒一次彩纸（`burst`），同一天只播放一次。
- 休息日：显示「今天不打怪」和距离下个工作日上班的倒计时。
- 下班时发一次 `notice`：「下班啦」。正文不写金额。

## 常驻

- 常驻小画布按 `pinned_show` 显示：
  - 金额：金币图标加跳动金额，带 `roll`；
  - 下班倒计时：旗子图标加倒计时；
  - 两者轮换：每 8 秒切换一次，随常驻轮播节奏走。
- 插件本身不做打码。

## 验收

- 截图：
  - 上班中；
  - 午休（计薪和不计薪各一张）；
  - 通关；
  - 休息日；
  - 常驻的三种显示。
- 单元测试：
  - 当月工作日数；
  - 午休计薪开关对每秒金额的影响；
  - 各状态切换时刻；
  - 跨午夜的上下班设置（如 22:00–06:00）。
- 用 `DAOZAI_FRAME_TRACE=1` 确认：只有经验条在流动时，帧间隔正常，岛收起后不再出动画帧。
