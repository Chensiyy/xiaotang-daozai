# 岛仔插件 SDK v1 设计评审稿

## 1. 总览

插件包是一组有版本的文件。岛仔是宿主，SDK 是宿主允许作者调用的公开接口。作者提交要展示的数据、操作和配置；岛仔掌管界面、定时器、磁盘与网络。插件拿不到窗口对象、系统命令、账户凭据库或任意路径。一个插件可以向多个位置输出，但只有一个主要设置归属。

本分支只实现倒计时技术验证。以下接口名、预算和稳定性等级用于评审，示例采用 JavaScript 外观；WASM 通过适配库传递等价的有界值。正式宿主还需实现每项能力。**运行环境建议先选 QuickJS**，选型依据、执行故障、两种语言的作者成本及验证边界见[运行环境实测](runtime-spike.md)。最终选型由小唐决定。早期外部 PowerShell 命令草案无法提供这里约定的隔离，建议以独立制品格式区分，迁移后重新授权。

## 2. 第一版能力与作者示例

下表中 `sdk` 代表宿主提供的接口，`cfg` 是经宿主验证的配置快照。示例省略业务取数；回调只返回声明的数据。设置在清单里声明，运行时读取。插件不能把自己的绘制代码挂入 egui。

| 能力 | 作者写法（设计示例） | 用户在哪里看到 |
| --- | --- | --- |
| 开关、分段选择 | `{key:"show-label",label:"显示标签",type:"switch",default:true}`；`{key:"density",label:"密度",type:"segment",choices:["紧凑","宽松"],default:"紧凑"}` | 所属设置页同一张卡 |
| 数字、日期、文本 | `{key:"minutes",label:"间隔",type:"number",min:5,max:180,default:45}`；日期、文本的完整声明见第八节 | 所属页输入行；日期由宿主检验，数字超范围提示 |
| 常驻卡、临时卡 | `sdk.card.show({id:"next",mode:"resident",title:cfg.title,value:"8 天",pinnable:true})`；`sdk.card.show({id:"print",mode:"temporary",value:"3/8",ttlMs:5000})`；任务结束调用 `sdk.card.remove("print")` | 展开岛卡片；用户亲自固定后进入常驻栏；临时卡到期归还位置 |
| 独立模块 | `sdk.module.list(rows.map(r=>({id:r.id,title:r.name})))`；`sdk.module.detail(id,{text:row.note})`；`sdk.module.form("edit",fields,values)`；`sdk.onAction("save",persist)` | 功能栏 → 列表 → 详情或编辑表单；侧栏「功能」新增设置入口，页面管理新增模块开关 |
| 日程来源 | `sdk.calendar.replace([{id:"a1",title:"例会",start:"2026-12-01T10:00:00+08:00",end:"2026-12-01T11:00:00+08:00"}])` | 原生日程；宿主按来源和稳定 ID 更新或撤回，跨来源仅在共享事件标识一致时合并 |
| 音乐歌词来源 | `sdk.lyrics.publish({trackId:"t1",positionMs:2500,lines:[{atMs:2000,text:"窗边的小岛"}]})` | 音乐 → 来源；切换曲目先清旧歌词，过时的曲目 ID 丢弃 |
| AI 额度来源 | `sdk.quota.publish({windows:[{label:"本周",period_secs:604800,remaining_pct:72}]})` | AI 额度面板和用户选定的常驻账号；复用额度草案的单位、范围和缺失值语义 |
| 外观及无代码包 | `{"runtime":"assets","capabilities":["appearance.skin"],"assets":["theme.json"]}`（清单片段）；如需伙伴表情或图标，声明 `appearance.pet` 或 `appearance.icon` 并列出图片 | 外观 → 皮肤、伙伴或图标选择器。缺帧回退内置素材；关闭伙伴后表情素材不显示 |
| 私有存储 | `const last=await sdk.storage.get("lastDays"); await sdk.storage.put("lastDays",days)`；清单设 `dataVersion:1` | 重新打开继续；模块设置可导出数据 |
| 定时和事件 | `sdk.timer.every("refresh",60000,refresh)`；`sdk.events.on("focus.finished",appendLog)` | 定时更新当前数据；设置 → 专注与健康 → 完成后。用户关闭自动记录仍可手动记一条 |
| 受控网络、文件、提醒 | `await sdk.net.get("https://api.example.com/usage")`；`await sdk.files.read(handle)`；`sdk.notifications.show({id:"job-8",text:"打印完成"})` | 首次启用授权、系统文件选择器、一次性提醒。重复通知 ID 由宿主去重 |

## 3. 界面与宿主接入

| 作者声明 | 岛仔接入点 |
| --- | --- |
| switch / segment / number | `extras.rs` 的 `setting_row`、`settings_segmented`、`setting_number`。复用现有控件的范围、键盘操作和禁用样式 |
| text / date | `settings_control_row` + 单行 `TextEdit`；日期编辑复用本机日程表单的校验交互，持久化为 YYYY-MM-DD。验证分支用可编辑日期文本 |
| 设置分组、模块头 | `settings_card` 和 `settings_feature_header` 供名称、说明、开启状态及「打开」入口使用；增添原功能选项就放入原卡片 |
| 功能页、岛上卡片 | 复用 `Card` 的绘图、裁剪和字形适配；数据驱动的列表、详情和编辑表单由宿主响应点击、校验文本 |
| 导航和模块开关 | 基于 `SETTINGS_GROUPS`、`PAGE_SETTINGS_TABS` 的现有映射增加按稳定 ID 的注册表。内置页号继续可用；插件没有硬编码的数组下标。启停统一走 `module_on` / `set_page_visible` 的模块语义 |

作者按用户实际会做的事选择一个设置归属：

| 用户要做什么 | 接入方式 | 例子 |
| --- | --- | --- |
| 在原功能中多一个选项、来源或开关 | 将设置声明到原功能公开的位置，由岛仔画统一控件 | 农历归日程，皮肤归外观，歌词来源归音乐 |
| 看一眼信息、等一次提醒 | 声明常驻或临时卡，把少量参数放到最相关的已有设置页 | 发薪日期去「待办与置物」改；打印进度的提醒偏好归「消息提醒」 |
| 反复新增、查找、编辑自己的内容 | 注册独立模块，功能栏完成日常操作，模块设置页调偏好 | 便签正文在岛上编辑，默认排序去便签设置改 |
| 希望某个事件发生后自动做事 | 订阅公开事件，把授权和开关放在主要归属页 | 专注结束后自动写日志；点“手动记一条”使用同一份数据 |

纪念日模块也可以提供固定倒数与日历记录，所有入口仍指向一个主要设置归属。「我的插件」统一提供前往设置、启停、卸载，岛上设置按钮也定位同一项。保留必要设置与关键提醒；多处重复说明合并在首次操作处；内容多、确有低频设置的页面才显示「高级」。

## 4. 三层开关与恢复

宿主持久化模块开关 M、用户对插件的启用意愿 P、每个显示位置或事件订阅的局部偏好 L。生效条件为 **所属 M 开且 P 开且当前权限已获准**。某项输出另需其 L 开、目标位置可用。独立模块的模块开关与插件开关共享同一用户意愿。「所属模块已停用」是宿主推导的原因，保留 P。插件不能改写全局偏好，只能在生效期间提供可撤销的外观值。单选来源由宿主保存用户的选择和最近可用来源。

| 讨论中的验收场景 | 模型推演 |
| --- | --- |
| ① 只关日历农历 | 日程 M、农历 P 开，日历 L 关、小岛 L 开。日历撤掉农历标签，岛卡继续 |
| ② 停用日程后再启用 | 日程 M 关，连带撤下农历插件全部输出和定时器，P 保留。开 M 后只恢复原 P 为开的扩展；用户手动停用的仍关 |
| ③ 纪念日跨模块 | 归属 M 是纪念日。日程关只撤下日历记录，纪念日列表和固定倒数仍可用。关闭纪念日后，「我的插件」同步显示已停用，功能入口、固定倒数和日历记录一并撤下。再开后恢复原文、日期和固定选择 |
| ④ 奶油 → 插件皮肤 → 胶囊改刘海 → 停用插件 | 安装后可随时在外观页切换内置与插件皮肤。停用解除皮肤覆盖，读取当前基础皮肤与用户形状，得到“奶油＋刘海”。大小、停靠、吉祥物沿用全局偏好；包内配色各自保存，材质参数仅在所选皮肤支持时生效 |
| ⑤ 停用、重启、卸载 | 停用立即递增该实例的代次，取消计时、网络及事件，忽略旧代次迟到的结果；回收卡片、来源和实例。重启保留已停用状态与数据；仅卸载时询问保留或删除用户内容 |

一次事件执行的存储和界面输出先暂存，结束且代次有效时再提交；错误、被撤权或超时丢弃本次输出。

## 5. 权限模型

清单声明能力、具体 HTTPS 主机、订阅事件和用户选择文件的只读权。安装时展示作者、版本、设置归属、使用位置和权限摘要；安装不代表同意联网或自动动作。首次启用按该版本声明展示“将访问哪个域名”“什么时候运行”“读哪个用户选择的文件”。例如清单片段 `"permissions":{"hosts":["api.example.com"],"files":["user-selected-read"],"events":["focus.finished"]}`。用户可撤权。更新先比较已授权能力与新清单的差异；扩大权限的版本须重新确认，通过后再切换。

引擎内只注册 SDK 白名单函数，禁用操作系统模块、动态原生加载、任意路径和原始套接字。宿主给每次调用绑定实例身份、代次及权限，不接受插件传来的身份。网络代理解析 URL 后按规范化精确主机、HTTPS、允许端口比较；每跳重定向重新校验，解析与连接地址都校验并拒绝内网/本机，拦截自设 Host，限制超时与响应体。用户通过宿主选择文件，实例拿到绑定文件的只读句柄；重解析点、符号链接、越目录、过期句柄和另一插件的句柄均拒绝。拒绝记录错误码与权限名；日志剔除路径、密钥和正文。验证代码只实测了有限沙箱和模拟传输，生产代理与授权系统仍须实现。

## 6. 数据生命周期

安装包只读放在 `%APPDATA%\Daozai\plugins\<id>\<版本>\`。建议宿主另存配置、授权、数据版本和内容于 `%APPDATA%\Daozai\plugin-data\<id>\`，凭据进 Windows 凭据管理器。插件通过键值访问私有空间；宿主按调用实例选目录、限制键和数据体积，写临时文件后原子替换。插件只收到它自己申请的值。

升级在数据副本中按 dataVersion 依次迁移，校验成功后一次切换包与数据；失败保留旧包与旧数据，显示恢复原因。导出由用户在所属设置页触发，以可读 JSON 和数据版本导出用户内容，排除密钥和已授权文件句柄。卸载撤销权限、删除程序和凭据；有用户创作内容时提供保留或删除选项。保留的内容只有同一插件身份的经审核版本可重新认领，不能仅凭同名取得。

## 7. 资源预算（供评审的起始值）

| 项目 | 建议值及宿主执行 | 用户看到什么 |
| --- | --- | --- |
| 周期刷新 | 普通数据至少 60 秒；前台倒计时或歌词按需放宽到 1 秒，同实例仅一次在途，合并积压请求 | 数据带更新时间；暂缓更新时保留最近有效值 |
| 执行/内存 | 单回调 30 ms、每实例 4 MiB 初始预算。JS 用堆上限和中断；WASM 限内存/表并计指令。两种机制都要有宿主线程外的看门狗 | 单次失败撤销本次写入；连续 3 次暂停插件，设置页允许手动重试 |
| 并发与网络 | 最多两个插件任务同时执行；每插件一个网络请求，10 秒、最多 256 KiB；停用取消。宿主异步处理 I/O，回调执行时重新核对代次 | 排队时岛体可继续操作，失败显示简短原因 |
| 岛上空间 | 建议最多固定 3 张插件卡，一次弹出 1 张临时卡；已满让用户选择替换。临时输出有失效时间 | 拒绝占位或排队，不挤掉原常驻顺序 |
| 私有数据 | 建议每插件 5 MiB（用户主动导出的文件独立计算）；先核算事务后的大小，再提交 | 写满提示清理或导出，已有内容可读 |

燃料是 WASM 解释器给指令分配的执行额度，和毫秒没有固定换算；SDK 开工前要在慢机上校准。原生解析、宿主 I/O 和引擎自身缺陷也需另设边界，生产版是否启用独立低权限工作进程见第十三节。

## 8. 包与清单

包根含 `plugin.json`，代码入口如 `src/main.js` 或 `bin/main.wasm`，资源如 `assets/icon.png`。版本包不可覆盖。完整机器可检验格式见 [JSON Schema](sdk-v1.schema.json)。Schema 是清单字段及类型的约束；宿主还须做跨字段和文件内容校验。

```json
{
  "id":"tang.countdown","name":"纪念日倒数","author":"示例作者",
  "version":"1.0.0","api":1,"runtime":"js","entry":"src/main.js",
  "owner":"tasks","capabilities":["settings","card","storage","timer"],
  "dataVersion":1,"permissions":{},
  "settings":[
    {"key":"title","type":"text","label":"标题","default":"纪念日"},
    {"key":"target","type":"date","label":"目标日期","default":"2026-12-25"}
  ]
}
```

ID 采用小写作者命名空间和稳定名称，以点分隔，最长 64 字符；路径限制为包内相对路径。包校验还要检查重复 ID/设置键、缺失入口、枚举默认值、日期有效性、数值范围、入口与引擎是否匹配、能力与权限的一致性。自有模块须使用 self 与 module；资源包只准许可的素材格式，禁脚本、外链及含活动内容的资源。解包限制数量、总字节、路径规范化和链接；先在暂存区校验再替换。JS 与 WASM 制品不可直接加载动态库。

## 9. 版本与兼容

包版本独立于接口主版本 api 和数据版本 dataVersion。建议首发稳定基础清单、身份、设置控件、卡片模型和存储语义；新模块注册、实时歌词、事件和来源适配先标实验性。稳定接口允许新增可选项并定义旧插件的默认值；改单位、删字段、改事件语义必须升主版本。宿主加载前按版本与能力分发适配器，不支持的版本保留配置并提示升级；实验能力失配明确列出，不能悄悄改变稳定字段的解释。权限扩大始终重新授权。

建议六个月并行期仅承诺给已定稿的稳定主版本。发布回归从上个稳定发布的归档获取**原始包及其校验值**，在新宿主上试装、恢复数据、触发事件、切换主题和停用，再用同一组断言比较。最终兼容期限由小唐确认。

## 10. 开发者模式与自测

建议由开发者模式选择本地目录，先解析清单，再在独立测试身份和数据目录中加载。保存文件后防抖重载，变更会撤销旧实例的计时器、挂起请求与输出；权限扩大单独复核。预览提供浅/深色、100%/150% 缩放、顶部/左右停靠以及模拟日期、断网和事件。开发包与市场包身份分隔。

拟议的 `daozai --plugin-test <目录> --report <目录>` 运行清单/素材校验、禁止访问和允许访问、权限更新、断网回退、上下级启停、卸载/重装、旧接口原包测试和多外观截图。报告含插件/宿主/接口版本、每项通过/失败/跳过、错误位置、脱敏原因、耗时、快照与 PNG 路径；失败返回非零退出码。本分支的 `--sdk-spike` 是实验测量入口，两者分别命名。

## 11. 从本体改动拆成插件

先把 PR 差异拆成业务计算、固定平台控件、后台任务和本体通用修复。保留独立输入输出及原测试；参数归属映射到上表，将定时、文件和联网替换为 SDK 能力。比如现有健康设置 `setting_number(ui,"提醒间隔",&mut self.settings.water_minutes,5,180," 分钟",1.0)`，插件清单对应 `number/min=5/max=180` 和带分钟的标签；宿主负责画控件与校验，插件只读取 `cfg.minutes`。需要公开能力却尚无接口时，提出最小输入输出，并保留本体修复的独立提交。

可复制给 AI：

> 阅读这个分支与目标分支共同祖先以来的改动、我的实际使用场景和 SDK 设计。列出可以抽出的逻辑与测试、仍属于本体的修复、缺少的公开接口。选一个设置归属，逐个映射控件。生成最小清单与源码、公开能力和权限列表、启停与数据迁移样例。用合成数据验证局部显示、上级停用、重启和卸载；只标记实际运行通过的项，把待宿主验证的项单列。保留原作者与素材许可。

## 12. 投稿与市场的接口约定

作者向独立插件仓库提 PR，交付 ID、维护者、主页与反馈渠道、包/接口/数据版本、权限差异、依赖、许可证、源代码和可复现构建命令。CI 消费清单、不可变包、库依赖清单、源码提交、测试数据和第十节的报告。变更宿主权限或发布二进制时应可定位到对应源码及审核结论。

审核通过后，索引按 ID+版本关联包的 SHA-256、字节数、接口要求、下载源、签名与签名密钥标识。生产客户端验证签名、哈希及吊销状态，再原子安装。吊销按具体 ID、版本或制品哈希定位，附原因和替代版本；对已安装命中版本停止加载并保留数据。镜像先同步包与吊销信息，再发布相应索引。市场、反馈系统、仓库和流水线部署由后续工作处理。
